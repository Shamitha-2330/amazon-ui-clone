# Amazon UI Clone

A static front-end clone of the Amazon home page, built with HTML and CSS as a layout practice project.

> **Disclaimer:** This is an educational UI clone for practice only. It is not affiliated with, endorsed by, or connected to Amazon. It has no backend, and no data is collected, stored, or transmitted.

## Features

- Static desktop layout of the Amazon home page
- Header with logo, search bar and navigation
- Product and category sections laid out in a grid
- Footer with link columns
- Clean, semantic HTML and organised CSS

## Tech Stack

- HTML5
- CSS3 (Flexbox, Grid)

## What I Practiced

- Recreating a complex, content-heavy page layout
- Flexbox and CSS Grid for headers, product cards and footers
- Structuring HTML with semantic elements
- Consistent spacing, typography and colour styling

## Scope

This project is a **desktop-oriented static layout**. It is not responsive and has no interactivity or backend.

## Project Structure

```
amazon-ui-clone/

```

Adjust the tree to match your actual folder layout.

## Run Locally

```bash
git clone https://github.com/Shamitha-2330/amazon-ui-clone.git
cd amazon-ui-clone
```

Open `index.html` in your browser, or use the Live Server extension in VS Code.
